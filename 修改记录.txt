一、代码修改（1个文件）
----------------------------------------------------------------

文件: neushare-backend/src/main/java/com/neushare/config/WebMvcConfig.java

修改内容:
  1. 新增 import:
     - java.io.File
     - org.springframework.beans.factory.annotation.Value
     - org.springframework.web.servlet.config.annotation.ResourceHandlerRegistry

  2. 新增字段:
     @Value("${file.upload.path:uploads}")
     private String uploadPath;

  3. 新增方法 addResourceHandlers():
     将 uploads 目录映射为 /files/** 静态资源路径
     重启后端后，通过 http://localhost:8080/files/文件名 即可下载文件

二、数据库表结构修复
----------------------------------------------------------------

以下表在当前数据库中不存在或缺少字段，已补建:

  1. post 表 (社区帖子表)
     - 字段: id, user_id, title, content, tags(JSON), image_urls(JSON),
       files(JSON), is_recommended, view_count, like_count,
       favorite_count, comment_count, status, create_time, update_time

  2. post_like 表 (帖子点赞记录)
     - 字段: id, user_id, post_id, create_time
     - 唯一键: (user_id, post_id)

  3. post_favorite 表 (帖子收藏记录)
     - 字段: id, user_id, post_id, create_time
     - 唯一键: (user_id, post_id)

  4. post_comment 表 (帖子评论)
     - 字段: id, post_id, user_id, content, parent_id, deleted,
       create_time, update_time

  5. follow 表 (关注关系)
     - 字段: id, follower_id, followed_id, create_time
     - 唯一键: (follower_id, followed_id)

  6. notification 表 (通知)
     - 字段: id, user_id, type, resource_id, from_user_id, title,
       content, is_read, create_time

  7. user 表新增字段:
     - resource_count BIGINT DEFAULT 0   (上传资源数)
     - follower_count BIGINT DEFAULT 0   (粉丝数)
     - following_count BIGINT DEFAULT 0  (关注数)
     - total_likes_received BIGINT DEFAULT 0 (总获赞数)

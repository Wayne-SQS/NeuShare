# NeUshare 配色美化方案

> 设计原则：**亮色清新跳脱 · 深色极简专业**
> 两种主题使用完全不同的视觉语言，而非简单的「同一色系加深/变浅」

---

## 一、设计语言概述

### 亮色主题（Light）
- **关键词**：清新 / 跳脱 / 多彩 / 玻璃质感 / 轻盈
- **视觉语言**：多彩渐变、毛玻璃卡片、大量留白、灵动的小圆点
- **适用场景**：日常浏览、资源分享、社交互动

### 深色主题（Dark）
- **关键词**：高级 / 专业 / 极简 / 黑白灰 / 精致点缀
- **视觉语言**：仅黑白两色 + 小圆点点缀、无彩色、无渐变
- **适用场景**：深夜阅读、专注学习、文档编辑

## 二、亮色主题 — 清新跳脱 · 玻璃质感

### 2.1 色彩分配表

| 用途 | 色值 | 说明 |
|------|------|------|
| **品牌主色** | `#4A6BFF` | 清爽靛蓝，年轻不幼稚 |
| **品牌辅色 A** | `#FF8FB1` | 粉色，温柔活力 |
| **品牌辅色 B** | `#C4B5FD` | 薰衣草紫，高级质感 |
| **品牌辅色 C** | `#89CFEF` | 天空蓝，清新通透 |
| **品牌辅色 D** | `#00C2CB` | 青蓝，科技灵动 |
| **页面背景** | `#F4F7FF` / 渐变 | 淡蓝白基底，营造清透感 |
| **卡片背景** | `#FFFFFFB8`（80%白） | 毛玻璃主卡，配 `.blur(40vp)` |
| **卡片背景 次** | `#FFFFFFE6`（90%白） | 次要卡片，透明度降低但更清晰 |
| **输入框背景** | `#FFFFFFCC`（80%白） | 毛玻璃输入框 |
| **主文字** | `#1E2A5C` | 深靛蓝，比纯黑更有温度 |
| **次要文字** | `#5A6A9C` | 中靛蓝灰 |
| **提示文字** | `#A0B0D8` | 浅靛蓝灰 |
| **功能色-成功** | `#89CFEF` | 天空蓝 |
| **功能色-警告** | `#FFB5A7` | 柔桃色 |
| **功能色-错误** | `#FF6B6B` | 珊瑚红 |
| **分割线** | `#D4DCF055`（透明度33%） | 极淡蓝灰，几乎看不见 |

### 2.1.1 辅色使用场景规范

| 辅色 | 色值 | 使用场景 | 示例 |
|------|------|---------|------|
| **辅色A 粉** | `#FF8FB1` | 收藏/点赞激活态、视频教程标签、女性用户头像底色 | 收藏按钮点击后变粉、视频类型资源标签 |
| **辅色B 薰衣草** | `#C4B5FD` | 教程笔记标签、高亮提示、徽章/勋章、评分星星 | 教程类型标签、五星评分、成就徽章 |
| **辅色C 天空蓝** | `#89CFEF` | 成功状态、默认类型标签、在线状态、关注按钮 | 上传成功提示、默认资源类型、用户在线指示器 |
| **辅色D 青** | `#00C2CB` | 软件工具标签、链接文字、次级操作按钮 | 软件类型标签、"查看更多"链接、"取消"按钮 |
| **主色 靛蓝** | `#4A6BFF` | 主按钮、导航栏激活态、书籍文档标签、品牌标识 | "提交"按钮、底部导航选中态、书籍类型标签 |

**使用原则**：
1. 每个页面最多使用 3 种辅色（主色 + 2种辅色），避免色彩过多
2. 主色占比 60%，辅色各占 15-20%，留白 10%
3. 同一功能在不同页面保持一致（如收藏按钮永远是粉色）

### 2.2 玻璃质感（Glassmorphism）核心参数

```
━━ 玻璃卡片 ━━
.backgroundColor   #FFFFFFB8    (80% 透明白)
.backdropBlur      40vp
.border            1vp solid #FFFFFF80
.shadow            radius: 24vp, color: #4A6BFF15, offsetY: 6vp
.borderRadius      20vp

━━ 玻璃输入框 ━━
.backgroundColor   #FFFFFFCC    (80% 透明白)
.backdropBlur      20vp
.borderRadius      12vp

━━ 玻璃导航栏 ━━
.backgroundColor   #F4F7FFCC    (70% 透明淡蓝白)
.backdropBlur      40vp
.borderBottom      0.5vp solid #4A6BFF20
```

### 2.3 多彩渐变系统（用于 Banner / Hero / 点缀）

| 渐变色 | 用途 |
|--------|------|
| `#4A6BFF → #00C2CB` | 主渐变 Banner（蓝青） |
| `#FF8FB1 → #C4B5FD` | 暖渐变 Banner（粉紫） |
| `#89CFEF → #00C2CB` | 清新渐变（天青） |
| `#4A6BFF → #FF8FB1` | 对比渐变（蓝粉） |
| `#C4B5FD → #89CFEF` | 梦幻渐变（紫天） |

渐变方向统一为 **135°**（左上→右下）。

### 2.4 小圆点 / 小方块装饰系统（亮色模式专属）

```
● 小圆点色盘:  #4A6BFF · #FF8FB1 · #C4B5FD · #89CFEF · #00C2CB
● 尺寸分级:   4vp · 6vp · 10vp · 14vp
● 位置规则:
   - Banner 边缘随机散布 5~8 个小圆点
   - 卡片右上角 1 个 10vp 小圆点（品牌色）
   - 空状态页面 14vp 主色小圆点 + 周围 4 个 6vp 辅色小圆点
   - 列表项前 4vp 小圆点（类型色），替代传统竖条标签
● 透明度:     60%~90%
● 动画:       轻微微浮动 4vp · 6s 循环 · ease-in-out
```

### 2.5 类型标签配色（多彩）

| 资源类型 | 色值 | 样式 |
|---------|------|------|
| 视频教程 | `#FF8FB1` | 粉底+白字 圆角胶囊 |
| 书籍文档 | `#4A6BFF` | 靛蓝底+白字 圆角胶囊 |
| 软件工具 | `#00C2CB` | 青蓝底+白字 圆角胶囊 |
| 教程笔记 | `#C4B5FD` | 薰衣草底+白字 圆角胶囊 |
| 默认 | `#89CFEF` | 天空蓝底+白字 圆角胶囊 |

### 2.6 玻璃视觉层次

亮色模式通过**透明度**而非阴影来构建层次：

```
Level 0  页面背景              #F4F7FF          纯色基底
Level 1  主卡片 (毛玻璃)        #FFFFFFB8 + blur(40)  主要内容
Level 2  次卡片 (更透明)        #FFFFFFE6 + blur(20)  次要内容
Level 3  弹出层 (最不透明)      #FFFFFFF5 + blur(60)  模态/对话框
```

## 三、深色主题 — 极简黑白 · 高级专业

### 3.1 色彩分配表（严格两色系）

| 用途 | 色值 | 说明 |
|------|------|------|
| **基础色** | `#FFFFFF` | 纯白，仅用于文字最高强调 |
| **页面背景** | `#0E0E10` | 极深灰（非纯黑，减少 OLED 纯黑光晕） |
| **卡片背景** | `#1C1C1F` | 深灰，与背景有 5% 明度差，形成层级 |
| **输入框背景** | `#161618` | 比卡片略深，增加凹陷感 |
| **主文字** | `#F2F2F4` | 近白（非纯白，减少刺眼） |
| **次要文字** | `#8A8A93` | 中灰 |
| **提示文字** | `#6B6B73` | 深灰（对比度 4.5:1，符合 WCAG AA） |
| **分割线 / 边框** | `#2A2A2E` | 极淡边框（明度差 ~6%） |
| **功能色-成功** | `#E8E8EC` | 白（用边框+文字表达成功，不用彩色） |
| **功能色-警告** | `#FFFFFF`（加粗+边框） | 白，通过视觉强度区分 |
| **功能色-错误** | `#FFFFFF`（加粗+边框+图标） | 白，通过图标强度区分 |

> **重要**：深色模式**严禁**使用任何彩色（蓝、粉、黄、绿、红）。所有强调通过**白色强度、加粗、边框、图标、小圆点**实现。

### 3.2 小圆点点缀系统（深色模式核心装饰）

```
● 点的尺寸:   2vp · 3vp · 5vp · 8vp
● 点的颜色:   #FFFFFF （纯白，只靠大小和透明度变化）
● 透明度层级:  15% · 30% · 50% · 80% · 100%

● 位置规则:
   - 页面顶部 Banner 区: 散布 15~20 个 2vp/3vp 点（透明度 15%~50%），营造星空感
   - 卡片左上角/右下角: 1 个 8vp 白点（透明度 80%），仅在重要卡片上出现
   - 按钮内部: 点击态时添加 3vp 白色小圆点（透明度 30%）从中心扩散
   - 空状态页面: 由 5 个不同大小的点组成极简图形
   - 未读通知: 5vp 实心白点 + 外圈 8vp 30%透明度光圈
   - 导航栏激活态: 图标下方 4vp 小圆点（替代传统底部横条）

● 动画:  柔和呼吸 透明度 40%→70%→40% · 5s 循环 · ease-in-out
```

### 3.3 按钮设计（纯黑白）

```
━━ 主按钮 (Primary) ━━
.backgroundColor   #FFFFFF
.color             #0E0E10
.fontWeight        700
.borderRadius      14vp
.shadow            无（或极淡 #00000080）

━━ 次按钮 (Secondary) ━━
.backgroundColor   transparent
.color             #F2F2F4
.border            1vp solid #2A2A2E
.borderRadius      14vp

━━ 文字按钮 (Tertiary) ━━
.backgroundColor   transparent
.color             #8A8A93
.hover效果         color → #F2F2F4
```

### 3.4 标签设计（纯黑白）

深色模式下，资源类型**不以颜色区分**，改用：

| 资源类型 | 样式 |
|---------|------|
| 视频教程 | `VID` 三个大写字母 · 细边框胶囊 |
| 书籍文档 | `BOOK` 四个大写字母 · 细边框胶囊 |
| 软件工具 | `SOFT` 四个大写字母 · 细边框胶囊 |
| 教程笔记 | `NOTE` 四个大写字母 · 细边框胶囊 |
| 默认 | `OTHR` 四个大写字母 · 细边框胶囊 |

> 标签统一为 `#1C1C1F` 背景 + `#8A8A93` 细边框 + `#8A8A93` 文字。点击态才变为白色。

### 3.5 深色模式唯一可使用的「强强调」手段

由于不使用彩色，深色模式下**强调信息**通过以下方式实现：

| 强调等级 | 实现方式 | 适用场景 |
|---------|---------|---------|
| L1 (最强) | 纯白文字 + Bold(800) + 5vp 小圆点 | 关键数据、重要通知 |
| L2 (强) | 纯白文字 + Medium(600) | 主要操作、标题 |
| L3 (中) | 近白 `#F2F2F4` + Regular | 正文内容 |
| L4 (弱) | 中灰 `#8A8A93` | 次要说明、时间、标签 |
| L5 (最弱) | 深灰 `#4E4E55` | 占位提示、已读信息 |

### 4.2 小圆点装饰组件（ColorDot.ts）

```typescript
// 亮色模式多彩点 / 深色模式纯白点
// 用法：ColorDot({ size: 10, color: '#4A6BFF', opacity: 0.8 })

@Builder
function ColorDot(size: number, color: string, opacity: number = 1.0) {
  Circle({ width: size, height: size })
    .fill(color)
    .opacity(opacity)
    .margin({ right: 6 })
}
```

## 七、落地建议

### 7.1 分阶段实施

| 阶段 | 改动 | 理由 |
|------|------|------|
| **第一阶段** | 替换 `ColorTokens.ets` 全局色值 | 立即可见效果 |
| **第二阶段** | Banner/卡片/按钮添加毛玻璃效果 | 提升质感 |
| **第三阶段** | 添加小圆点装饰组件 | 点睛之笔 |
| **第四阶段** | 深色模式标签改为字母缩写 | 深化极简风格 |
| **第五阶段** | 添加小圆点动画（呼吸/微浮动） | 高级感加分项 |

### 7.2 技术要点

1. **毛玻璃实现**：HarmonyOS 原生支持 `.backdropBlur()`，无需自定义绘制
2. **透明度色值**：`#FFFFFFB8` 格式 = `#` + RGB(FFFFFF) + Alpha(B8)。B8(十六进制) = 184/255 ≈ 72%
3. **深色模式判断**：`@StorageLink('colorMode')` 或通过系统 API 读取
4. **小圆点装饰**：用 `Stack` + `Circle` 组合实现，不占用布局空间
5. **避免滥用**：小圆点只在 Banner / 卡片角落 / 空状态处出现，不要每处都加

### 7.2.1 毛玻璃性能优化策略

**问题**：`backdropBlur()` 在列表滚动时会造成性能下降，尤其在低端设备上

**解决方案**：

1. **分级使用策略**
   - **高优先级**（必须用毛玻璃）：顶部导航栏、Banner、弹窗背景
   - **中优先级**（可选）：首页资源卡片（前 5 个可见卡片）
   - **低优先级**（不用）：列表中的次要卡片、详情页底部卡片

2. **滚动时降级**
   ```typescript
   @State isScrolling: boolean = false;
   
   List() {
     // 列表内容
   }
   .onScrollStart(() => { this.isScrolling = true })
   .onScrollStop(() => { this.isScrolling = false })
   
   // 卡片组件中
   GlassCard({
     blurRadius: this.isScrolling ? 0 : 40  // 滚动时关闭模糊
   })
   ```

3. **设备分级降级**
   ```typescript
   // 根据设备性能等级调整
   const deviceLevel = await device.getDeviceLevel();
   const blurRadius = deviceLevel === 'low' ? 0 : 40;
   ```

4. **替代方案**
   - 低端设备：用半透明纯色背景替代毛玻璃（`#FFFFFFE6` 而非 `#FFFFFFB8 + blur`）
   - 中端设备：降低模糊半径（`blurRadius: 20` 而非 `40`）
   - 高端设备：完整毛玻璃效果

### 7.3 推荐搭配的其他设计元素

| 元素 | 亮色 | 深色 |
|------|------|------|
| 圆角 | 20vp（柔和） | 14vp（利落） |
| 阴影 | 淡彩阴影 `#4A6BFF15` | 几乎无阴影，靠边框 |
| 间距 | 20/16/12vp 三级 | 16/12/8vp 四级 |
| 字体粗细 | Regular(400) / Medium(600) | Regular(400) / Bold(700) / Black(800) |

## 八、与原方案的核心区别

| 对比项 | 原有方案（珊瑚红） | 新方案（亮多彩/暗黑白） |
|--------|------------------|---------------------|
| **亮色主色** | 珊瑚红 `#FF5A5F`（暖色调、偏成熟） | 清爽靛蓝 `#4A6BFF`（冷色调、年轻化） |
| **亮色背景** | 纯白 `#FFFFFF`（刺眼、单调） | 淡蓝白 `#F4F7FF`（清透、有层次） |
| **亮色质感** | 纯扁平、无变化 | 毛玻璃卡片 + 多彩渐变 |
| **亮色装饰** | 无 | 小圆点系统（多彩） |
| **亮色辅色** | 单一珊瑚红 | 粉+薰衣草+天空蓝+青（无黄无绿） |
| **深色主色** | 珊瑚红 `#FF5A5F`（彩色仍保留） | **纯白 `#FFFFFF`**（唯一强调色） |
| **深色背景** | `#121212`（纯黑灰） | `#0E0E10`（极深灰，OLED 更柔和） |
| **深色质感** | 扁平卡片 | 极细边框 + 黑白明暗对比 |
| **深色功能色** | 红/绿/黄彩色 | **全白**，靠强度/图标/边框区分 |
| **深色装饰** | 无 | 小圆点星空系统 + 呼吸动画 |
| **两主题关系** | 同一色系的深浅变化 | **完全不同的视觉语言** |
